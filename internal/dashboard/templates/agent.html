Encryption × signing. Signing and end-to-end (e2e) encryption cannot be combined: to sign, the gateway must read the content. With signing required, the gateway sees every message in plaintext, so use encrypt: pgp for sensitive content and TLS on every non-localhost path between agents and the gateway. Grant e2e only to agents whose content the gateway must never see, and set their Require signing to no; those messages are not signed.
